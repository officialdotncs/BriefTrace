# Learner Profile

## Initial Idea
BriefTrace: an AI-powered tool that converts university assignment briefs into a clear, verifiable requirements checklist. A student pastes an assignment brief; the app extracts deliverables, deadlines, formatting rules, grading criteria, and constraints, then presents them as an organized checklist. Key differentiator: each extracted requirement points back to the relevant text in the original brief (traceability), so the student can verify the AI interpreted it correctly. The app should flag confusing instructions or missing information rather than guessing.

Intended users: university students trying to understand complicated assignment briefs.
Motivation: "I want to build something that genuinely helps people rather than another generic AI chatbot."

> Used by the planning skills to shape the idea without re-asking onboarding questions.

## Demonstrated Technical and Agent Experience
Primarily builds hackathon projects using Bolt.new. Prefers a solo, AI-assisted workflow. Not yet comfortable with Node.js, Git, or terminal commands. Hasn't established a regular workflow with other coding agents beyond Bolt.

Evidence: "I primarily use Bolt.new to build my hackathon projects... I'm not comfortable with Node.js, Git, or terminal commands yet."
